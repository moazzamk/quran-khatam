A plugin for Quran recitations

== Description ==
This plugin adds two elements to your WordPress. One is a form to sign up for khatms and the other is a table to display khatm status.

== Installation ==

# From Gutenberg Editor:

1. Go to the WordPress Block/Gutenberg Editor
2. Search For **khatam**
3. Click on the **khatam form and khatam table** to add the block

# Download & Upload:

1. Download the **Quran Khatm** plugin (.zip file)
2. In your admin area, go to the Plugins menu and click on **Add New**
3. Click on **Upload Plugin** and choose the **alert-box.zip** file and click on **Install Now**
4. Activate the plugin and Enjoy!

# Manually:

1. Download and upload the **Quran Khatm** plugin to the **/wp-content/plugins/** directory
2. Activate the plugin through the **Plugins** menu in WordPress
